# AI Usage

This document describes how AI assisted during the development of the Restaurant Order Management App.

## AI Tool Used

- ChatGPT (OpenAI)
- Github Copilot

## How AI Was Used

### 1. Project Architecture
- Discussed the overall application architecture.
- Planned the navigation and state management approach.

### 2. Code Assistance
AI assisted with generating and refining code for:

- Login screen
- Orders context and custom hook
- AsyncStorage service
- Orders list screen
- Order details screen
- Reusable UI components:
  - OrderCard
  - StatusBadge
  - SearchBar
  - StatusFilter
- TypeScript models and enums

### 3. Technical Guidance
AI provided guidance on:

- React Context API
- AsyncStorage integration
- React Navigation setup
- TypeScript typing
- Component organization and separation of concerns

### 4. Documentation
AI assisted in drafting:

- README.md
- AI_USAGE.md

## Developer Responsibility

All generated code was reviewed, integrated, tested, and modified as needed before being included in the final submission.
